# Hương Miền — Cultural V3

Phiên bản tinh chỉnh theo góp ý:
- Mở rộng miền Trung từ Thanh Hóa đến Khánh Hòa.
- Thêm hình ảnh gợi địa danh vào card Box và bản đồ hương vị.
- Chỉnh lại typography, màu sắc và cảm giác không gian văn hóa ẩm thực.
- Vẫn là website demo tĩnh, có thể deploy ngay bằng Vercel Drop.

## Deploy
1. Vào https://vercel.com/drop
2. Kéo file ZIP `huong-mien-cultural-v3-vercel-ready.zip` hoặc kéo toàn bộ thư mục này.
3. Chọn Deploy.

## Chạy local
Chỉ cần mở `index.html` hoặc dùng Live Server.
